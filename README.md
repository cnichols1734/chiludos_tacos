# CHILUDOS Fine Street Tacos - Website

Official website for CHILUDOS Fine Street Tacos, Mont Belvieu's favorite authentic Mexican restaurant.

## Tech Stack

- **HTML5** - Semantic, accessible markup
- **CSS3** - Custom properties, Grid, Flexbox, animations
- **JavaScript** - Vanilla JS with IntersectionObserver, smooth scroll
- **CDN Libraries:**
  - Google Fonts (Inter, Nunito, Playfair Display)
  - Font Awesome 6.5 (icons)
  - AOS (Animate on Scroll)

## Deployment (Cloudflare Pages)

1. Push to GitHub repository
2. Connect repo to Cloudflare Pages
3. Build settings:
   - **Framework preset:** None
   - **Build command:** (leave empty)
   - **Build output directory:** `/` (root)
4. Deploy

## Features

- Responsive single-page design

- Loading screen animation
- Back-to-top button
- Print-friendly styles
